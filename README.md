Chroma Grid Cards
An interactive and responsive card gallery built using React, JavaScript, HTML and CSS.

📌 About the Project
Chroma Grid Cards is a creative React web project featuring six themed cards with beautiful images, grayscale effects, colourful hover animations and a modern user interface.

✨ Features
Six creative themed cards
Hogwarts, Books, Crochet, Iceland, New York and Science
Grayscale images with colourful hover effects
Smooth animations and transitions
Responsive design for desktop and mobile
Modern dark-themed interface
🛠️ Technologies Used
React.js
JavaScript
HTML5
CSS3
Vite

🚀 How to Run the Project
Download or clone the repository.
Open the project in VS Code.
Open the terminal.
Install dependencies:
npm install
Start the development server:
npm run dev
Open the local URL displayed in the terminal.
🎯 Project Objective
The main objective of this project is to demonstrate React component development, responsive layouts, CSS animations and interactive user interface design.
